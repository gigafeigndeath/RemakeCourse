# IT-КУБ • Находка

**Платформа дополнительного IT-образования для детей и подростков 7–17 лет**

Современная веб-платформа для IT-Куба в городе Находка (Приморский край). Позволяет ученикам учиться, общаться с преподавателями в реальном времени, а администраторам — удобно управлять процессом.

---

## ✨ Основные возможности

- **Главная страница** с описанием направлений, партнёрами и призывом к действию
- **Система авторизации и регистрации** пользователей
- **Реал-тайм чат** между учениками и преподавателями (на базе WebSocket)
- **Админ-панель** для преподавателей:
  - Список всех учеников с быстрым переходом в чат
  - Полноценная таблица всех пользователей
  - Управление ролями (только главный администратор может делать других админами и забирать роль)
  - Удаление пользователей
- **Адаптивный и современный дизайн**
- **SEO-оптимизация** (`sitemap.xml` + `robots.txt`)

---

## 🛠 Технологии

- **Backend**: PHP 8.1 + MySQL + PDO
- **WebSocket**: Ratchet (PHP)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Сервер**: Nginx + PHP-FPM
- **Авторизация**: Сессии + `password_hash()`

## 🚀 Как запустить проект

1. Склонировать репозиторий
2. Настроить подключение к базе в `config.php`
3. Импортировать `setup.sql` в базу данных
4. Запустить WebSocket-сервер:
   ```bash
   cd /var/www/itcubechat.ru
   sudo -u www-data php ws_server.php
   (или через systemd-сервис)

Настроить Nginx (конфиг уже есть в репозитории)
